# Android client

This directory is reserved for the independent Android companion app. The Android Studio project has not been added yet.

When adding it, keep the app source and its own Gradle configuration here. Do not commit the TVS Connect APK, decompiled source, signing keys, personal BLE captures, or rider-specific logs. Shared protocol documentation lives in [`../docs/bike_ble_protocol.md`](../docs/bike_ble_protocol.md).
