# Project instructions

- Keep the iOS and Android apps visually consistent. Match screen structure, labels, typography scale, spacing, colors, and component sizing across both platforms whenever changing the UI. When a UI change is needed on one platform, make the corresponding change on the other in the same task.
- Keep feature behavior and settings in parity across iOS and Android. Document platform limitations where the operating system APIs differ.
- Prefix shell commands with `rtk` as instructed by the workspace environment.
